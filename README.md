# Flowmate — GitHub Pages Landing

정적 HTML/CSS/JS만 사용하는 랜딩페이지입니다.

## 바로 올리는 방법

1. 새 GitHub repository를 만듭니다.
2. 이 폴더의 `index.html`, `style.css`, `script.js`를 repository root에 올립니다.
3. `index.html`에서 `YOUR_FORM_URL`을 Google Form 또는 Tally 상담 폼 주소로 바꿉니다.
4. GitHub → Settings → Pages → Build and deployment → Deploy from a branch
5. Branch를 `main`, folder를 `/(root)`로 선택하고 Save 합니다.
